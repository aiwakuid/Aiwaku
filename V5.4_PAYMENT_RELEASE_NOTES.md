# AIWAKU V5.4 — Payment Experience

- Cash checkout now records a real paid payment through `record_cash_payment` and updates order balance/status atomically.
- QRIS checkout creates a Midtrans payment attempt and shows a focused payment sheet.
- QRIS status is polled from the tenant-readable payments table and becomes paid only after the verified webhook updates the row.
- No demo payment-success shortcut is used.
- The POS remains one-flow: select menu → checkout → cash complete or QRIS payment sheet.

## Release gate
Run `npm ci`, then `npm run typecheck`, `npm test`, and `npm run build` in an environment with registry access. Apply `schema.production.sql` before testing cash checkout.
