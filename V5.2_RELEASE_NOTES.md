# AIWAKU V5.2 — Experience Upgrade

## North star
**Powerful by default. Simple by design. Delightful to use.**

## Included
- Simplified navigation into Beranda, Jualan, Operasional, Bisnis, and Pengaturan.
- Rebuilt dashboard as a calm command center rather than a technical status page.
- Action-first cards for sales, booking, stock, customers, and reports.
- Concise AIWAKU daily insights with a maximum of three signals.
- Improved responsive/mobile layout and touch targets.
- Removed technical implementation/status language from the primary UX.
- Removed runtime dependency on a remote Google Fonts import.
- Updated package identity to `aiwaku-v5` version `5.2.0`.
- Added `EXPERIENCE_PRINCIPLES.md` as the UX north star.
