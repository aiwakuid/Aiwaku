# AIWAKU V5.6 — Table & Dine-in Experience

## Fokus
Membuat dine-in terasa sederhana: pilih meja → jualan → kitchen tahu meja.

## Perubahan
- Table map 12 meja (T01–T12).
- POS memiliki pemilihan meja ketika mode Dine-in aktif.
- Metadata dine-in disimpan bersama order melalui `custom_text` dalam format JSON agar kompatibel dengan schema order yang ada.
- KDS menampilkan nomor meja untuk order dine-in.
- Table map membaca order aktif tenant dan menampilkan meja tersedia/digunakan.
- Supabase Realtime digunakan untuk memperbarui status meja.

## Batasan sengaja
V5.6 belum mengklaim split bill, merge table, move table, atau seat-level billing sebagai fitur production. Fitur tersebut membutuhkan model data transaksi meja yang lebih eksplisit dan atomic payment allocation.
